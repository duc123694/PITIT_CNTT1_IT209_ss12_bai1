# Spring Boot Gradle CI

Project Spring Boot toi gian de chay unit test bang Gradle va GitHub Actions.

## Chay test local

```bash
./gradlew test
```

Tren Windows PowerShell:

```powershell
.\gradlew.bat test
```

## Workflow

Workflow nam tai `.github/workflows/ci.yml` va tu dong chay khi push len nhanh `main`.
